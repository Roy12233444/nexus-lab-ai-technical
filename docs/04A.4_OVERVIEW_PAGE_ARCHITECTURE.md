# 4. 📐 Section-by-Section Specifications

### Section 01: Identity / Hero (`identity-hero`)

- **Container Width:** `reading` (768px) to optimize typographic measure and immediate comprehension.
- **Components:** Monospace overline (`Nexus LAB AI`), fluid H1 display (`AI Systems Innovation Company`), body-lg lead (`Researching, engineering, and validating durable intelligent-system capabilities`), real-time status indicator (`CORE ARCHITECTURE : ACTIVE`), and quick milestone badges (`01 LOCKED`, `02 LOCKED`, `03 LOCKED`).

### Section 02: Thesis / Worldview (`thesis-worldview`)

- **Container Width:** `reading` (768px)
- **Components:** Problem callout block contrast, core hypothesis statement, and first-principles rationale.

### Section 03: Mission & Scope (`mission-scope`)

- **Container Width:** `reading` (768px)
- **Components:** Primary mission statement card, 3 explicit boundary rules (Not a SaaS wrapper; Not a random app collection; Products are downstream fruits).

### Section 04: Innovation Engine (`innovation-engine`)

- **Container Width:** `content` (1280px)
- **Components:** Dual-column layout: formal definition and purpose on the left; structural pipeline stages (`Problem → Research → Engineering → Validation → Capability`) on the right.

### Section 05: NSEM Methodology (`nsem-methodology`)

- **Container Width:** `content` (1280px)
- **Components:** Tabbed or dual-layer visualizer presenting the 5-Stage Macro Lifecycle (`INSPIRATION → FORMALIZATION → VALIDATION → ENGINEERING → IMPACT`) alongside the 8-Step Iterative Micro Engineering Loop.

### Section 06: Architecture Hierarchy (`architectural-hierarchy`)

- **Container Width:** `wide` (1440px)
- **Components:** 4-tier interactive or structural hierarchy card grid:
  1. **Roots:** Foundational Beliefs, Constitution, KER
  2. **Trunk:** NSEM Methodology, Innovation Engine, Validation Framework
  3. **Branches:** NALA, AMP, RTA-GUARD, COSMOS
  4. **Fruits:** Validated Technologies, Downstream Products

### Section 07: Research Programs (`research-programs`)

- **Container Width:** `content` (1280px)
- **Components:** Responsive 2x2 grid (`.nexus-grid-2`) rendering program cards driven by `src/content/overview/overview.ts`:
  - **NALA:** Multi-timescale Agent Harness | `IMPLEMENTED` / `VERIFIED`
  - **AMP:** Cognitive Memory Architecture | `IMPLEMENTED` / `VERIFIED (Phase 1)`
  - **RTA-GUARD:** Constitutional AI Safety Middleware | `IMPLEMENTED` / `REPORTED`
  - **COSMOS:** Multi-Orbital Operating System | `SPECIFIED` / `DOCUMENTED`

### Section 08: Evidence & Validation (`evidence-validation`)

- **Container Width:** `content` (1280px)
- **Components:** Grid of concrete evidence cards showcasing verified proof artifacts (JIRA-007 1-Hour Chaos Soak Test log, Rust Param Hash & Erasure tests, ARIES recovery engine).

### Section 09: Maturity & Epistemic Boundaries (`state-matrix`)

- **Container Width:** `content` (1280px)
- **Components:** Multi-axis epistemic matrix table making explicit what is built, what is experimental, what is reported, and where active open questions remain.

### Section 10: System Exploration (`system-exploration`)

- **Container Width:** `content` (1280px)
- **Components:** 4-column gateway cards routing technical visitors into deep dossier tracks (`Research Explorer`, `Technology Capabilities`, `Evidence Chains`, `Philosophy & Horizon`).
