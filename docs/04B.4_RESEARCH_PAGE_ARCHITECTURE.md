# 3. 📐 Section-by-Section Specifications

### Section 01: Research Identity / Hero (`research-hero`)

- **Container Width:** `full` (Edge-to-edge canvas with structured central content container).
- **Purpose:** Establish the intellectual authority of the Nexus research track.
- **Components:** Monospace overline (`Nexus LAB AI Research`), H1 display (`Sovereign Research Vectors`), lead paragraph, live status indicator (`RESEARCH TRACK : ACTIVE`), and dual action triggers (`EXPLORE PORTFOLIO →`, `VIEW TRUTH TABLE →`).

### Section 02: Research Thesis (`research-thesis`)

- **Container Width:** `content` (1280px).
- **Purpose:** Explain the first-principles necessity for solving runtime state collapse, memory amnesia, safety divergence, and space-grade latency.
- **Components:** Left column thesis statement; right column 4-pillar problem-to-solution breakdown.

### Section 03: Core Research Portfolio (`research-portfolio`)

- **Container Width:** `content` (1280px).
- **Purpose:** Present the four sovereign research projects (**NALA**, **AMP**, **RTA-GUARD**, and **COSMOS**) as parallel vectors.
- **Hard Rule:** Strict project independence. Zero dependency arrows, hierarchical parent/child trees, or "powered by" couplings.
- **Components:** 2x2 responsive grid of technical project cards displaying identity, domain, core mission, current maturity badge, and evidence state.

### Section 04: Research Domains (`research-domains`)

- **Container Width:** `content` (1280px).
- **Purpose:** Classify the technical territories being explored.
- **Components:** 4-column capability cards:
  1. _Agent Execution_ (Runtime orchestration & fault recovery)
  2. _Durable Memory_ (Multi-tier persistent retention & identity)
  3. _AI Safety & Governance_ (Constitutional middleware & audit logs)
  4. _Multi-Orbital Systems_ (Delay-tolerant satellite infrastructure)

### Section 05: Evidence & Maturity Matrix (`research-evidence-matrix`)

- **Container Width:** `wide` (1440px).
- **Purpose:** Display the transparent 4-axis truth table.
- **Components:** Interactive / responsive matrix table rendering exact states:
  - NALA: `IMPLEMENTED` / `VERIFIED` (1-Hour Chaos Soak Test)
  - AMP: `IMPLEMENTED` (Phase 1) / `VERIFIED` (Rust Persistence Core)
  - RTA-GUARD: `IMPLEMENTED` / `REPORTED` (70K LOC / 2K Tests Quarantined)
  - COSMOS: `SPECIFIED` / `DOCUMENTED` (Terrestrial Simulation Only)

### Section 06: Research Boundaries & Non-Claims (`research-boundaries`)

- **Container Width:** `content` (1280px).
- **Purpose:** Make explicit what is verified vs what is not claimed to prevent hype or marketing drift.
- **Components:** 4-card boundary deck isolating bounded proof from generalized assumptions.

### Section 07: Program Technical Dossiers (`research-gateways`)

- **Container Width:** `content` (1280px).
- **Purpose:** Provide clean doorways into deep individual program dossiers (`/research/nala`, `/research/amp`, `/research/rta-guard`, `/research/cosmos`).
- **Components:** 4 gateway cards with technical lead summaries, status chips, and arrow navigation triggers.

### Section 08: Closing Direction (`research-closing`)

- **Container Width:** `reading` (768px).
- **Purpose:** Reiterate the fundamental institutional ethos: "Roots Before Fruits".
- **Components:** Centered closing quote card with constitutional citation.

# 4. 🛡️ Invariant & Kill-Critic Guarantees

1. **Project Independence Enforced:** No operational dependencies between NALA, AMP, RTA-GUARD, and COSMOS exist in the blueprint.
2. **Zero Quarantined Leakage:** Quarantined claims (e.g. infinite autonomy, universal memory solved, 100% exploit prevention, in-orbit satellite flight) are excluded from all section slots.
3. **Data-Driven Architecture:** All sections consume `CANONICAL_RESEARCH_REGISTRY` (`src/content/research/research.ts`) directly without hardcoding duplicate content.
4. **Shell & Token Compliance:** Strictly utilizes Phase 02 design tokens and Phase 03 layout containers (`reading`, `content`, `wide`, `full`).
