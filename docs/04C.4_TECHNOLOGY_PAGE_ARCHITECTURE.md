# 1. 🎯 Purpose & Core Narrative

The **Technology Page (`/technology`)** answers one core question for the visitor:

> **"How does Nexus LAB AI engineer sovereign, fault-tolerant AI systems from first principles?"**

Unlike the Overview page (_Who we are_) or the Research page (_What problems we investigate_), the Technology page is strictly **engineering-oriented**. It unveils the underlying machinery, technical substrates, systemic capabilities, and multi-tier architectures powering Nexus LAB AI.

```text
========================================================================================
                      THE TRI-TRACK NARRATIVE DISTINCTION
========================================================================================
  04A OVERVIEW   (/)          : "WHO IS NEXUS LAB AI?" (Identity, Mission, Ecosystem)
  04B RESEARCH   (/research)   : "WHAT ARE WE INVESTIGATING?" (Parallel Research Vectors)
  04C TECHNOLOGY (/technology) : "HOW DO WE ENGINEER THESE SYSTEMS?" (Substrates & Machinery)
========================================================================================
```

# 5. ♿ Accessibility & Visual Slot Contracts

1. **Semantic Landmarks:** `<main id="main-content">` wraps all 8 sections; each section uses `<section id="..." aria-labelledby="...">`.
2. **Heading Hierarchy:** Exactly one `<h1>` in Hero; sequential `<h2>` and `<h3>` tags throughout.
3. **Decorative Visuals:** All technical vector substrate canvases and topology graphics must carry `aria-hidden="true"`.
4. **Keyboard Navigation:** All interactive cards, tabs, and gateway links must have high-contrast visual focus rings (`ring-2 ring-nexus-cyan`).
5. **Reduced Motion:** If animations are applied in `04C.5`, all transitions must respect `@media (prefers-reduced-motion: reduce)`.
