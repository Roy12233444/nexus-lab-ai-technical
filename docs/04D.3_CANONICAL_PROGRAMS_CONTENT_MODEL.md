## 4. 🛡️ Validation Rules & Defensive Invariants

The validation engine in [`src/lib/validation/programContentValidation.ts`](file:///D:/NEXUS-LAB-AI-TECHNICAL-WEBSITE/NEXUS-LAB-AI-TECHNICAL/src/lib/validation/programContentValidation.ts) enforces 6 canonical rules:

1. **RULE-001 (Provenance & Claim Linkage):** Every public program must reference valid, existing claims with authority tiers and source documents.
2. **RULE-002 (Quarantine Firewall):** Quarantined claims must have `publicAllowed: false`. Quarantined programs (`Lyra`, `ShadowTrace`, `SynaptiCode`) can never enter public selectors.
3. **RULE-003 (4-Axis Epistemic Decoupling):** Prohibits illegal state combinations (`IMPLEMENTED` + `VERIFIED` + `FUTURE`). Strictly protects COSMOS (`PLANNED`, `FUTURE`) and RTA-GUARD (`REPORTED`).
4. **RULE-004 (Sovereign Program Independence):** Prohibits runtime coupling, dependency arrows, or operational pipelines between programs.
5. **RULE-005 (Public Selector Isolation):** `getAllPublicPrograms()` must return exactly 8 programs.
6. **RULE-006 (Boundary Integrity):** Every public program must specify explicit non-claim boundaries.
