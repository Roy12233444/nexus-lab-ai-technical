## 6. ⚔️ Sovereign Independence & Anti-Coupling Invariants

$$\forall\ p_i, p_j \in \text{Programs},\ i \ne j \implies p_i \text{ is operationally decoupled from } p_j$$

1. **Zero Runtime Dependency Visualizations:**
   - ❌ No sequential execution pipeline graphs: `COSMOS → NALA → AMP → RTA-GUARD`.
   - ✅ Parallel sovereign presentation territories with shared philosophical foundation.
2. **Visual Hierarchy $\ne$ Operational Hierarchy:**
   - Primary vs Supporting vs Context-Bound reflects public presentation weight and scope, NOT runtime subordination.

## 7. 📱 Responsive Layout Architecture

- **Desktop ($\ge 1440\text{px}$):** Multi-column asymmetric layouts, side-by-side card comparisons, full matrix table views.
- **Laptop / Tablet ($768\text{px} - 1024\text{px}$):** 2-column card grids, horizontal scroll containers for dense data matrices.
- **Mobile ($320\text{px} - 767\text{px}$):** Single-column stacked layouts, preserved 4-axis badge readability, zero horizontal overflow.

---

## 8. ♿ Accessibility Contract (WCAG 2.1 AA)

1. **Semantic DOM Hierarchy:** Exactly one `<h1>` per page (in `programs-hero`); sequential `<h2>` for all sections; `<h3>` for individual program cards.
2. **Accessible Landmarks:** Semantic `<section>` wrappers with `id` and `aria-label` attributes.
3. **Screen Readers:** Decorative vector visuals marked `aria-hidden="true"`.
4. **Keyboard Navigation:** Focusable interactive elements with high-contrast `:focus-visible` outlines.
